# نظام التصميم وتجربة المستخدم — Ziwa Design System (Fluent 2 RTL)

> يجمع هذا المرجع لغة **Microsoft Fluent 2** المصقولة مع قدرات **Avalonia UI 11** الأصلية وتجربة المحررات العربية المتخصصة.

---

## 1. المبادئ الأساسية للواجهة
1. **RTL أصيل في الجذر:** تضبط `MainWindow` خاصية `FlowDirection="RightToLeft"` وتُصمّم جميع الشاشات والشبكات (`Grid`) والهوامش بالاعتماد على ترتيب `RightToLeft` الأصلي، مع استثناء صريح (`FlowDirection="LeftToRight"`) فقط لقيم أرقام الكود مثل Hex `#RRGGBB` والأبعاد التقنية `W × H` عند اللزوم.
2. **السلامة والوضوح قبل الزخرفة:** كل زر أيقوني يحمل `ToolTip.Tip` و`AutomationProperties.Name` واضحين؛ لا توصف الواجهة بحشو مكرر ولا تُوضع أيقونات تزيينية داخل عناوين الأقسام أو حقول المنزلقات.
3. **الربط المصرّف إجباري (`CompiledBindings`):** يُفعّل `<AvaloniaUseCompiledBindingsByDefault>true</AvaloniaUseCompiledBindingsByDefault>` في `Ziwa.App.csproj` وتُحدد `x:DataType` في كل `.axaml` لضمان صفر أخطاء ربط وقت التشغيل وسرعة إقلاع عالية.

---

## 2. قاموس التوكنز الموحّد (`Themes/Tokens.axaml`)
يُمنع كتابة ألوان Hex خام داخل صفحات العرض (`.axaml` Views). تُقرأ كافة الألوان والظلال والاستدارات عبر `DynamicResource`:

| الفئة | أمثلة التوكنز في `Tokens.axaml` | الغرض |
|---|---|---|
| **الأسطح (`Surfaces`)** | `ZiwaCanvasBackgroundBrush`, `ZiwaSurfaceBrush`, `ZiwaCardBrush`, `ZiwaSubtleFillBrush` | تدرج اللوحات الداكنة والفاتحة بتباين Fluent 2 هادئ |
| **الحدود والفواصل (`Strokes`)** | `ZiwaHairlineBorderBrush`, `ZiwaFocusStrokeBrush`, `ZiwaControlBorderBrush` | حدود شعرية نظيفة لفصل صفوف المفتش والبطاقات |
| **الإجراءات والحالات** | `ZiwaPrimaryActionBrush`, `ZiwaDestructiveActionBrush`, `ZiwaSuccessBrush`, `ZiwaWarningBrush`, `ZiwaInfoBrush` | ضمان تباين نصي `>= 4.5:1` في الثيمين الفاتح والداكن |
| **الاستدارة (`CornerRadius`)** | `ControlCornerRadius` (`4px`), `OverlayCornerRadius` (`6px`), `DialogCornerRadius` (`10px`) | توحيد الاستدارة (يُمنع `16px+` للبطاقات والحوارات) |
| **الأبعاد والكثافة** | `ToolbarButtonHeight` (`32`), `CompactButtonSize` (`28`), `RailWidth` (`56`), `InspectorWidth` (`280`), `RulerThickness` (`20`) | ثبات محاور المحاذاة عبر كل الألواح |

## 3. تخطيط مساحة العمل (`Workspace Shell`)
```text
┌─────────────────────────────────────────────────────────────────────────┐
│ شريط العنوان والقوائم المدمج (Frameless TitleBar · قوائم، ثيم، حساب)     │
├─────────────────────────────────────────────────────────────────────────┤
│ الشريط العلوي للأوامر (CommandBar: إدراج، تراجع/إعادة، أدوات، حفظ، طباعة) │
├──────┬───────────────────────────────────────────────────┬──────────────┤
│      │ [مسطرة أفقية 20px مثبتة]                           │              │
│ سكة  ├─────┬─────────────────────────────────────────────┤ لوح الخصائص  │
│الأدوات│مسطرة│   SkiaViewportHost (ورقة الرسم الحية)      │  المفتش      │
│(يمين)│رأسية│   + QuickBar السياقي العائم                │  السياقي     │
│      │     │   + مقابض التحديد والتدوير                  │  (يسار)      │
├──────┴─────┴─────────────────────────────────────────────┴──────────────┤
│ شريط الحالة السفلي (المقاس الفعلي mm، مستوى التكبير %، DPI الفعّال، الوضع) │
└─────────────────────────────────────────────────────────────────────────┘
```

- **فتح المفتش السياقي:** تحديد عنصر أو خلية يفتح لوح الخصائص تلقائياً إذا كان مغلقاً ويعيد الحالة السابقة عند إلغاء التحديد (ما لم يثبّته المستخدم يدوياً).
- **السياقية الذكية (درس `FF-05`):** تحديد ملصق بارامتري يُظهر بطاقة «تعديل الملصق / نسخ SVG» أولاً ويطوي أدوات الـ AI الفوتوغرافية تلقائياً لتفادي ازدحام المفتش.

## 4. الأوامر، الاختصارات، وتجربة الانتظار
- **السجل الوحيد للأوامر (`CommandRegistry`):** الاختصارات (`Ctrl+S/E/P/O/Z/Y/K`, `Ctrl+.` للـ Zen Mode, `Alt+1..4`)، شريط الأدوات، قوائم السياق، ولوحة الأوامر السريعة (`Ctrl+K`) تشير إلى نفس معرّفات الأوامر ولا تُعرف الاختصارات في أماكن متفرقة.
- **مؤشرات الانتظار الصادقة (`Wait UX`):**
  - أقل من `1s`: تنفيذ فوري بلا وميض انتظار.
  - `1–3s`: مؤشر دائري هادئ في موضع الإجراء.
  - أكثر من `3s` أو شبكة: عرض `IsIndeterminate` (أو نسبة حقيقية مقاسة فقط) مع زر **إلغاء** صريح يمرّر `CancellationToken` ويجمد الإجراء المكرر على نفس الهدف دون قفل بقية التطبيق بلا مبرر.
