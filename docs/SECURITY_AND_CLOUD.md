# الأمان، الحفظ، الذكاء الاصطناعي، والسحابة — Ziwa Security & Cloud

> كل بند هنا مبني على حواجز الأمان المختبرة في Grido Studio دون التراخي في أي طبقة.

---

## 1. سلامة الملفات والمشاريع المحلية (`Ziwa.Infrastructure.Persistence`)
- **الكتابة الذرية الإلزامية (`AtomicFileWriter`):**
  - خطوات الحفظ الوحيدة المسموحة للمشاريع والإعدادات والتصدير:
    1. الكتابة إلى ملف مؤقت في نفس المجلد (`{target}.{guid}.tmp`).
    2. استدعاء `fileStream.Flush(flushToDisk: true)` لضمان تفريغ كاش نظام التشغيل للقرص.
    3. الاستبدال الذري via `File.Move(tmpPath, targetPath, overwrite: true)` (أو `File.Replace` عند إبقاء نسخة احتياطية `.bak`).
    4. حذف `.tmp` في كتلة `finally` عند أي استثناء.
- **حارس التعافي (`CrashGuard`) والحفظ التلقائي:**
  - عند بدء الجلسة يُكتب قفل جلسة؛ إذا أغلق التطبيق بصورة طبيعية يُحذف القفل.
  - عند وجود قفل يتيم ولقطة تعافٍ أحدث، يُعرض على المستخدم خيار استعادة المشروع بأمان (مع منع حذف العمل قبل قرار المستخدم).
- **SQLite محلي منضبط:** تفعيل `PRAGMA journal_mode=WAL;` و`PRAGMA foreign_keys=ON;` وترحيلات إصدارية مرقمة (`SchemaMigrations`) بدلاً من تثبيت `VERSION = 1`.
- **تعقيم مدخلات الحافظة والمشاريع:** قبل حقن أي عنصر مقروء من الحافظة أو ملف خارجي، يجب أن يمر عبر `SchemaValidator`: فحص الحدود المنطقية، رفض `NaN`/`Infinity`، تعقيم مسارات الملفات ضد Path Traversal (`Path.GetFullPath`), وتعقيم ملفات `SVG` المستوردة.

### تنفيذ `P4-01` — عقد المشاريع والمكتبة والتعافي
- **`.ziwa`:** حزمة ZIP إصدارها `1` تحتوي `manifest.json` (نموذج المستند وفهرس الأصول) و`assets/<AssetId>.bin`. الصور تحتفظ ببايتاتها الأصلية وبصمة `SHA-256`، وSVG يحتفظ بنسخته المعقمة ومعرّفه `svg-<SHA-256>`. تُجمع الأصول من كل الصفحات والمجموعات وتعبئات الأشكال والخانات وقائمة الانتظار، دون تكرار الصور أو تخزين سجل Undo.
- **القراءة الآمنة:** تحميل الحزمة وفحصها كاملاً قبل استبدال الجلسة، دون استخراج مسارات يحددها الأرشيف. رفض المداخل/خصائص JSON المكررة، والمسارات غير المتوقعة، والأصول المفقودة، واختلاف البصمات أو الأنواع، والإصدارات المستقبلية. ترحيلات المستند تمر بسلسلة `IDocumentMigrator` متتابعة. تعقيم SVG يشمل مراجع CSS الخارجية وتعليمات stylesheet؛ لا تُقبل حزمة تغيّر التعقيم بصمة أصلها.
- **حدود الحزمة:** مستند JSON حتى `8 MiB`، بيان حتى `10 MiB`، حتى `4096` أصل، `128 MiB` للأصل الواحد و`512 MiB` لمجموع الأصول. الصورة حتى `100,000,000` بكسل وبحد أقصى `32768` بكسل للحافة؛ عمق JSON `128`، عمق المجموعات `16`، الصفحات `256` والعقد `100000` لكل صفحة. المصفوفات الاختيارية غير المهيّأة تحتفظ بقيمتها `null` خلال التسلسل.
- **الحفظ ودورة الحياة:** الكتابة المتدفقة تستخدم `IAtomicFileWriter.WriteAtomicallyAsync` بنفس ضمانات الملف المؤقت والتفريغ والاستبدال. الحفظ يلتقط المستند المعتمد، ويُبقي التعديلات اللاحقة غير محفوظة. جيل الجلسة ومراجعتها يحميان من نتائج الفتح المتأخرة، وقرارات «حفظ / تجاهل / إلغاء» تحمي الفتح والبداية السريعة والإغلاق. تغيّر التحديد/المعاينة المؤقتة لا يُعد حفظاً أو تعديلاً جديداً.
- **المكتبة:** `SqliteProjectRepo` يفهرس المسارات والعناوين والتوقيتات في `projects.db` باستخدام WAL ومفاتيح أجنبية واستعلامات معلّمة و`SchemaMigrations`. الملف هو مصدر الحقيقة؛ فشل الفهرسة بعد حفظه يُبلّغ منفصلاً. النسخة `.ziwabackup` تضم لقطة منطقية للفهرس والمشاريع الفعلية، لا نسخة من قاعدة مفتوحة قد تفقد WAL. حدودها `1000` مشروع، `128 MiB` للملف و`512 MiB` للمجموع، وبيان `1 MiB`. الاستيراد يتحقق من كل المشاريع قبل النشر إلى مجلد فريد، ويعتمد الفهرس بمعاملة، ولا يستبدل ملفات موجودة.
- **التعافي:** لكل تشغيل مجلد مستقل وقفل `FileShare.None`. الحفظ التلقائي يأتي بعد `5s` من استقرار تعديل معتمد، إلى لقطة `.ziwa` مستقلة دون تغيير الملف الأصلي. يُكتب البيان ذرياً بعد نجاح اللقطة الجديدة، فيبقى البيان السابق صالحاً عند الفشل. الجلسات الحية لا تُستعاد؛ اللقطات التالفة تبقى على القرص دون حذف صامت. الاستعادة تبدأ كمشروع غير محفوظ باسم جديد، ولا تُحذف اللقطة القديمة قبل نجاح الحفظ أو تأكيد التجاهل. `CompleteAsync` ينظف جلسة الإغلاق الطبيعي فقط؛ التخلص من الخدمة دون إكمال يترك التعافي.
- **المسارات والاختبار:** المسار الافتراضي `%LocalAppData%/ZiwaStudio`؛ `ProjectStorageOptions` قابل للحقن، و`ZIWA_DATA_DIRECTORY` يسمح بتشغيل مساحة بيانات منفصلة. بناء حاوية الخدمات لا ينشئ قاعدة أو جلسة تعافٍ؛ البدء يتم من دورة حياة التطبيق. اختبارات الوحدة وAvalonia.Headless تستخدم مجلدات مؤقتة، ولا تمس مكتبة المستخدم.

## 2. جسر الهاتف والخادم المحلي (`Ziwa.Infrastructure.LocalServer`)
- يُربط الخادم المحلي بعنوان الاسترجاع **`127.0.0.1` فقط** (عند الوضع المحلي أو عبر قناة آمنة عند الاقتران).
- كل مسار استقبال صور (`/api/upload`) يفرض:
  - سقف حجم صريح قبل القراءة الكاملة للذاكرة (`MaxRequestBodySize` مناسب لنوع الرفع + إرجاع `413 PayloadTooLarge`).
  - التحقق من التوقيع السحري للملف (`Magic Bytes`: PNG / JPEG / WebP / HEIC / SVG معقّم) لا الاكتفاء بالامتداد.
  - رمز جلسة مقترن عشوائي عالي الإنتروبيا لكل جلسة جسر هاتف (`BridgeSessionToken`) ومهل انتهاء صلاحية.
- عارض الصور المحلي يحفظ قواعد أمان المحتوى (`Content-Security-Policy: default-src 'none'; sandbox;`, `X-Content-Type-Options: nosniff`).

## 3. خط الذكاء الاصطناعي الهجين (`Offline AI + Cloud Modal`)
- **عزل الخلفية (أوفلاين مجاناً عبر `Microsoft.ML.OnnxRuntime`):**
  - يعمل بالكامل محلياً في خيط/تجمّع خلفي لا يلمس خيط الواجهة، مع قراءة حية لـ `CancellationToken`.
- **ماسح المستندات (`OpenCvSharp`):**
  - كشف زوايا المستند (تحديد تلقائي مع تعديل يدوي) + تصحيح المنظور ثنائي الخط + 5 فلاتر مسح ضوئي متكافئة رقمياً مع `Ziwa.Rendering`.
- **ترميم الوجوه ورفع الدقة (`Modal CPU` — YuNet + Real-ESRGAN 2x + CodeFormer):**
  - **مهلة 180 ثانية + إلغاء صريح، وبلا إعادة محاولة تلقائية:** منع إهدار الحصة عند انقطاع الشبكة أو طول المعالجة.
  - **المصادقة حصراً بتوكن المستخدم:** `Authorization: Bearer <UserJWT>` — يُمنع منعاً باتاً تضمين أي مفتاح API ثابت أو سر مشترك في ثنائيات التطبيق.
  - **صدق الحصة والملكية:** الحصة اليومية تُحسم عبر استجابة الخادم الموثقة وتُمسح فوراً عند تسجيل الخروج (`auth-logout`). كل طلب يحمل معرّف المحاولة/الهدف كي لا تُطبق نتيجة متأخرة على عنصر محذوف أو مقفل أو مشروع مغلق.

### تنفيذ `P4-02` — الذكاء الاصطناعي المحلي الأوفلاين والمستورد الآمن
- **عزل الخلفية وكشف الوجه (`OnnxBackgroundRemover` / `OnnxFaceFramingService`):** يعملان حصراً في خيط خلفي عبر `Microsoft.ML.OnnxRuntime` (`InferenceSession`) باستخدام نماذج ONNX المضمّنة أو نماذج خارجية اختيارية تحت `{StorageRoot}/Models/`، دون أي اتصال شبكي أو أسرار مدمجة، مع إنهاء الاستدلال فوراً عبر `RunOptions.Terminate` عند تفعيل `CancellationToken`.
- **حماية الأصول وملكية العمليات:** يُحفظ `OriginalAssetId` غير قابل للفقد أثناء العزل وتعديل القناع وتأطير الوجه لإتاحة الاستعادة الكاملة، وتتحقق تذكرة `OperationTicket` (`ExpectedGeneration`، `TargetPageId`، `ExpectedSourceAssetId`) من عدم تطبيق أي نتيجة متأخرة على مستند مبدّل أو عنصر محذوف أو مقفل.
- **فحص استيراد الصور (`FileImageAssetImporter`):** يتحقق من المسار الكامل وسقف الحجم (`<= 128 MiB`) والتوقيع السحري الفعلي (`PNG / JPEG / WebP / BMP`) قبل تمرير البايتات إلى `AssetStore`.

## 4. Supabase Auth & RLS Policies
- **قاعدة الجلسة الواحدة (Last-Wins):** تُدار في دوال Postgres موثّقة (`SECURITY DEFINER`) مع تثبيت `SET search_path = public, pg_temp;`، ومنع الثقة بترويسات قابلة للتزييف من العميل.
- **حماية سياسات RLS:** تجنب الشروط الملتبسة مع القيم الفارغة `NULL` باستخدام صيغ صارمة مثل `IS NOT TRUE` في فحص الحظر/الإيقاف، وحصر استدعاء الدوال الحساسة بـ `authenticated` و`service_role` وفق أقل صلاحية ممكنة.
- **الخطأ الصادق:** عند فشل تجديد التوكن لسبب شبكة مؤقت لا تُمسح الجلسة المحلية فوراً حتى يثبت رفض الخادم الفعلي (`invalid_grant` / `401`/`403` موثّق).
