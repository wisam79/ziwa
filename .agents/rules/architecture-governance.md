# قواعد الحوكمة والمعمارية (Architecture & Governance)

- **بروتوكول الاستئناف الحي:** ابدأ أي مهمة تطويرية بقراءة «مؤشر الاستئناف الحي» في `docs/DEVELOPMENT_PLAN.md` والتوجه المعتمد. لا تفعّل بنداً مؤجلاً أو تبدأ مرحلة جديدة تلقائياً قبل إغلاق معايير المرحلة الحالية أو إذن صريح من المالك.
- **عزل الطبقات (`Layers Boundary`):**
  - الاعتماد أحادي الاتجاه: `Ziwa.App → Ziwa.Application / Ziwa.Rendering → Ziwa.Domain`.
  - يُمنع استيراد `Avalonia.*` أو `System.Net.Http` أو `System.IO.File` في `Ziwa.Domain` و`Ziwa.Rendering`.
  - تتحدث `Ziwa.App` مع الخدمات عبر واجهات `Ziwa.Application` فقط.
- **حظر الازدواجية والكود الميت:** وحّد أي دالة/ثابت/عنصر متكرر (مثل التحويل المليمتري، محاذاة الشبكة، ثوابت الأوامر، فلاتر المسح، تنبيهات الخطأ، قوالب الحقول) في مصدر حقيقة واحد، واحذف أي ملف أو نوع بلا مستهلكين (`Zero Importers`).
- **الحفظ الذري وفحص المدخلات:** كل كتابة ملف دائم تستخدم `AtomicFileWriter` (`*.tmp` + `Flush(true)` + `Move overwrite`). كل حمولة مقروءة من الحافظة أو ملف مشروع أو شبكة تخضع لفحص مخطط وأرقام منتهية موجبة (لا `NaN`/`Infinity`).
- **الأحداث والأوامر من مصدر واحد:** يُمنع استخدام أسماء أحداث نصية متفرقة أو تكرار منطق أمر بين القائمة والـ QuickBar واختصارات الكيبورد؛ استخدم `CommandRegistry` فقط.
- **بوابة التوثيق الرشيقة (`Fragment-First`):** لأي تعديل سلوكي أنشئ `fragment` واحداً في `changelog/fragments/` (لا `CHANGELOG` يدوي)، وحدّث المستند المتأثر فقط دون اختراع أرقام أو مسارات من الذاكرة، ثم مرّر `node scripts/docs-gate.mjs --strict-refs`.
